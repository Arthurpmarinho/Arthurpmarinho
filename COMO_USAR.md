# Como funciona este repositório

Este é o repositório especial de perfil. O README.md aparece no topo de github.com/Arthurpmarinho.

## Projeto novo no portfólio

1. Deixe o repositório público e preencha a descrição (About) em inglês.
2. Adicione o tópico `portfolio` e outros tópicos de tecnologia (ex.: `esp32`, `kicad`). Os tópicos viram a coluna Stack.
3. Pronto. Na segunda-feira seguinte ele entra na tabela. Para atualizar na hora, vá em Actions, "Update profile README", "Run workflow".

## Repositório de outra conta ou organização

Coloque `dono/repositorio` em `extra_repos` no config.json (ex.: o Micromouse em fcte-pi1).

## Nome bonito na tabela

Use `display_names` no config.json. Sem isso, o nome do repositório é usado.

## Texto fixo

A parte "What I have worked on" e "Tools" é escrita à mão. Só o que está entre os marcadores `<!-- ... -->` é gerado.

## Esconder um repositório da lista "Recently updated"

Coloque o nome dele em `exclude` no config.json.
